# Blue Lock: Egoist Career

Jogo de navegador feito por fã, inspirado no mangá/anime **Blue Lock**: você cria o seu jogador, entra no Blue Lock na posição 299 e sobe até o topo do mundo. Partidas em pixel art, cenas de cinema, Fluxos, armas, química com os companheiros, Liga Neo Egoísta, carreira profissional e Copa do Mundo.

## Como jogar

1. Baixe o projeto (botão **Code → Download ZIP**) e extraia.
2. Abra o arquivo `index.html` no **Google Chrome** (ou Edge).
3. O progresso fica salvo no próprio navegador.

Não precisa instalar nada nem ter internet.

### No celular

Abra **https://vinimarianotp.github.io/jogo-blue-lock/** no navegador do celular e jogue **deitado**: na partida aparecem um joystick e os botões (CHUTAR, PASSE, DRIBLE, CARRINHO, CORRER, Fluxo, Química e as skills).

Para instalar como app (ícone na tela, tela cheia, funciona sem internet e se atualiza sozinho):
- **Android (Chrome):** menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial").
- **iPhone (Safari):** botão Compartilhar → **Adicionar à Tela de Início**.

O save do celular é separado do save do PC (cada navegador guarda o seu). Para levar a sua carreira de um lugar para o outro: na tela inicial, **📤 EXPORTAR SAVE** (copia um código ou baixa um arquivo) e, do outro lado, **📥 IMPORTAR SAVE**.

## Controles na partida

| Tecla | Ação |
|---|---|
| WASD | mover |
| SHIFT | correr |
| ESPAÇO | driblar |
| Botão esquerdo | chutar (Q/E: com curva) |
| Botão direito | passe |
| F | carrinho |
| R | pedir a bola |
| 1–6 | skills da arma |
| G | Fluxo |
| C | Reação Química |
| ESC | pausa |

## Música própria

Coloque arquivos `.mp3` na pasta `musica/` com os nomes listados em `musica/LEIA-ME.txt` para tocar no lugar das trilhas do jogo. Esses arquivos ficam só no seu computador.
